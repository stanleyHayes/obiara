# Provider diligence evidence handoff

This metadata-only contract records independent procurement review for Atlas,
object storage/CDN, LiveKit and communications. Every provider requires current
evidence for DPA, subprocessors, processing locations, retention, deletion,
key control, support, breach response, cost and exit portability.

References are opaque 64-character identifiers. Source agreements, personal
data, credentials, quotes and provider payloads stay in their approved evidence
system. Issuer and reviewer roles must differ. Synthetic, pending, incomplete,
stale, duplicated or replayed evidence fails closed.

Validation is not selection, legal approval, account creation, purchase,
configuration or a network call. A passing record remains evidence metadata and
must be consumed by the separate launch-gate authority process.
