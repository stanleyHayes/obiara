# Market-pack and terminology governance

Each proposal is an immutable version based on one exact current master
catalog. It must contain every key exactly once, preserve the exact placeholder
multiset, and retain registered do-not-translate terminology.

Publish-ready status requires distinct professional-translation, paid
community-language and in-context reviewers, each completing fixed substantive
checks with opaque evidence, followed by a separate authorized approver with
an opaque reasoning reference. The boundary does not overwrite a registry,
deploy, activate a market, or treat machine translation as review.
