# Member Suban explanation and appeal

Members can see the bounded events behind their own thresholded marks, using
generic effect labels and source categories. Numeric credits, hidden bands,
provenance references, raw evidence, content, and third-party identities are
not projected.

Only adverse events can be appealed. Filing never edits or deletes the source
ledger event. A distinct authorized human reviewer records an upheld or
overturned outcome with an opaque reasoning reference; this boundary does not
change marks, safety rulings, matching, ranking, or visibility.
