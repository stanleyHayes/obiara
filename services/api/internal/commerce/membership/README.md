# Membership pass lifecycle

This boundary grants a versioned pass from an opaque receipt, preserves an
explicit immutable paid-through date, permits at most fourteen days of grace,
and records member cancellation without shortening the purchased term.
Refunds remain pending until a provider-confirmed opaque fact is supplied.

The model exposes no romance-access promise, seed/visibility/rank coupling,
silent renewal, provider call, raw payment/member data, or mutable historical
term. MongoDB stores opaque references and the append-only lifecycle audit.
