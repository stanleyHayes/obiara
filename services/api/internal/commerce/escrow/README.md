# Escrow settlement

An escrow has an immutable opaque funding reference, funded GHS amount and
versioned milestone terms. Each milestone requires distinct delivery and
acceptance evidence before settlement. Statements expose gross, fee and net,
and total settlement cannot exceed funding.

A dispute permanently freezes transitions and retains its opaque Mpanyimfo
escalation reference. There is no member transfer, provider call, raw
member/payment data, hidden fee, unilateral term mutation, or dispute deletion.
